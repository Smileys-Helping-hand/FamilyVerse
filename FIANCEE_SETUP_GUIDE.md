## 📱 Step 1: Get the App Running

### On Your Phone or Computer:

1. **Ask [your boyfriend] to run these commands:**
   ```bash
   npm run db:push    # Create the database
   npm run dev        # Start the app
   ```

2. **Go to:** http://localhost:3000/events

3. **Create a new event:**
   - Click **"Plan Event"** button
   - Name it: **"Girls Evening"** (or your event name)
   - Set the date and location
   - Click **Create**

4. **You'll see a new "🎯 Planning" tab** at the top of the event - click it!

That's it! The app is ready. ✨

## 💡 Pro Tips & Tricks

### Tip 1: Share Early!
Send the WhatsApp message as soon as you create the event. Cousins can join and see the budget.

Click "Customize" to break down R100 the way YOU want:
- Maybe it's R70 food + R30 drinks?

### Tip 3: Let Your Cousins Claim Items
Don't assign everything yourself. Let them claim what they'll bring.
- They feel involved ✓

When someone marks an item bought, enter the actual price paid.
- Budget gets accurate
- Future events are easier to plan

### Tip 5: Add Extras
See a new vendor idea? Click **"Add Item"** and add it to the list.
- Build as you plan
