## 🚀 Quick Start (5 Minutes)

### Step 1: Set Up the Database
```bash
npm run db:push
```
This creates the tables for budgets, contributions, shopping, etc.

### Step 2: Start the Development Server
```bash
npm run dev
```
Opens at http://localhost:3000

### Step 3: Create an Event
- Go to `/events`
- Click **"Plan Event"**
- Name it: "Girls Evening"
- Set date/location
- Create event

### Step 4: Enter the Planning Tab
- Click the new **"🎯 Planning"** tab
- You'll see:
  - Budget breakdown (interactive!)
  - WhatsApp share button (big green!)
  - Shopping list tab
  - Shop finder tab
